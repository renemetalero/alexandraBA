6. VALIDACIÓN DEL TRAMO ON-PREMISE → AZURE
======================================================================

Una vez habilitadas las dos gestiones anteriores, Networking debe validar
que la red On-Premise tenga conectividad hacia Azure.

Validar:

1. Ruta existente desde On-Premise hacia Azure.
2. Ruta de retorno desde Azure hacia la red corporativa/AWS.
3. Reglas de firewall habilitadas.
4. Puerto TCP/443 permitido.
5. Resolución DNS correcta para los hostnames utilizados.
6. Acceso hacia la IP privada o servicio privado en Azure.
7. No existencia de traslape de CIDR entre AWS y Azure.
8. Confirmación de que el tráfico no requiere exposición pública.


======================================================================
7. PRUEBAS DE CONECTIVIDAD
======================================================================

Desde el workload en AWS:

Validación DNS:

nslookup detectidv8desa.banagricola.com


Validación HTTPS:

curl -vk https://detectidv8desa.banagricola.com


Validación puerto:

nc -vz 172.32.88.217 443

nc -vz 172.19.11.65 443


También validar:

- Logs de la aplicación.
- Logs del firewall.
- Trazabilidad del tráfico.
- Respuesta HTTP del servicio.
- Que el tráfico siga la ruta AWS → On-Premise → Azure.
